AI-Powered Government Subsidy & Eligibility Navigator

A CivicTech platform that simplifies access to government welfare schemes through intelligent eligibility matching, AI-powered policy explanations, and an accessible user-first experience.

📌 Overview

Millions of citizens miss out on welfare benefits simply because government schemes are difficult to discover, understand, and compare.

The AI-Powered Government Subsidy & Eligibility Navigator was developed in association with Gram Panchayat, Sawargaon, to bridge this information gap and improve financial inclusion.

The platform helps users:

Discover relevant Central and Maharashtra Government schemes
Instantly check eligibility based on personal details
Understand complex policy documents in simple language
Compare multiple schemes in one place
Access information through a mobile-friendly interface
🎯 Problem Statement

Government welfare information is often:

Scattered across multiple websites
Written in complex administrative language
Difficult for rural citizens to interpret
Time-consuming to research manually

As a result, many eligible beneficiaries remain unaware of available financial assistance and social welfare programs.

💡 Solution

The platform acts as a digital welfare navigator, enabling users to find suitable schemes within seconds.

By combining:

Intelligent eligibility filtering
AI-generated policy summaries
Interactive visualizations
Mobile-first design

the application significantly reduces the effort required to identify and understand government benefits.

✨ Key Features
🧠 Smart Eligibility Engine

A rule-based filtering system built using modern JavaScript that evaluates:

Age
Annual income
Profession
Gender
Social category
Land ownership
Employment status

and matches users with relevant government schemes in real time.

Examples include:

Pradhan Mantri Awas Yojana (PMAY)
PM-Kisan
Mahatma Jyotiba Phule Jan Arogya Yojana (MJPJAY)
Various Maharashtra State Welfare Schemes
🤖 AI-Powered Policy Simplification

Integrated Google Gemini API to transform lengthy government documentation into:

Easy-to-understand summaries
Simplified eligibility explanations
Benefit highlights
Actionable guidance

This makes welfare information accessible even to users with limited familiarity with policy terminology.

📊 Interactive Analytics & Visualization

Implemented dynamic dashboards using Chart.js to:

Visualize available schemes
Categorize benefits
Improve information discovery
Enhance user engagement
📱 Mobile-First User Experience

Designed with accessibility and usability in mind.

Features include:

Responsive layouts
Tailwind CSS interface
Smooth navigation
Print-friendly reports
Lightweight performance for low-bandwidth environments
